One funny line: a single joke that lands on a cold read. This entry's line asks a smart speaker for something relaxing — and gets the least relaxing answer imaginable.

## Run it

```sh
python3 main.py
```

It checks the line (one sentence, 1–200 characters, no line breaks) and writes it to `/output/entry.txt`.
